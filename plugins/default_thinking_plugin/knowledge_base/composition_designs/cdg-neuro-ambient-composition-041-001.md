## Artistic Reading

- User image / premise: A 24-minute self-hypnosis journey guiding attention from external orientation to protected internal absorption and back, using continuous vocal-prosody carrier as the primary hypnotic engine
- Musical problem: Creating a non-verbal, continuous lead that guides attention without demanding active tracking while maintaining hypnotic depth progression
- Listener stance: Following the continuous lead through breath-length phrases without monitoring or tracking effort
- What this is not: Pop melody, dramatic narrative, cinematic tension, or rhythmic groove-based entrainment
- Style-family fit: Structured Self-Hypnosis Journey (foreground_vocal_led_prosody) with continuous vocal-prosody carrier as the musical engine

## Chosen Musical Premise

- Premise sentence: A continuous sarangi-like carrier delivers breath-length falling-settling phrases over evolving harmonic bed, guiding attention through seven hypnotic stages with micro-developments in texture and spatial posture
- Primary dramatic motion: Establish → deepen → fractionate → stabilize → return (with continuous carrier as the unbroken thread)
- Sound-world metaphor: A slow-moving river of warm light that deepens into a sunken forest, briefly opens to sky through canopy gaps, then returns to the river's surface
- Musical consequence: Harmonic bed shifts from F major (open fifths) to Db minor (luminous shadow) then back to F with softened upper partials; carrier register descends 1.5 octaves while maintaining foreground audibility
- Duration rationale: 24 minutes allows for seven distinct hypnotic stages with micro-developments (15-45s events) and meso-changes (75-150s transitions), preventing stasis while maintaining trance continuity

## Hypnotic Function Architecture

- Target use: Music-only self-hypnosis for focused immersive listening
- Stage map:
  - Orientation / Settling: 0:00-3:00, baseline-to-light depth, function: establish safety through carrier-first pairing
  - Induction / Narrowing: 3:00-7:00, light-to-medium depth, function: pace attention inward via lengthened rests
  - Deepening: 7:00-13:00, medium-to-deep depth, function: reduce orienting load through register descent
  - Core Absorptive Work: 13:00-20:00, deep depth, function: sustain absorption via sparse motif fragments
  - Fractionation Pocket: 20:00-22:00, deep-to-light-medium-to-deep depth, function: brief lightening then deeper return
  - Integration / Stabilization: 22:00-23:30, medium-to-light depth, function: stabilize with orientation-cell return
  - Return / Reorientation: 23:30-24:00, light-to-baseline depth, function: reorient through spatial contraction
- Depth trajectory: Register descent (C3→G2), harmonic density reduction (F major → F with fewer color tones), spatial widening (narrow→wide) then contraction
- Pacing-and-leading plan: First pace broad listening with slow ground (8s attack), then lengthen rests, lower register, darken brightness
- Ratification plan: Carrier's falling-settling contour returns at depth thresholds (induction, deepening stability, core reassurance)
- Suggestion-compatible windows: 7:30-9:00 (induction), 13:00-18:30 (core work), 22:00-23:00 (integration)
- Reset avoidance rule: No abrupt cuts, hard transients, or sudden brightness spikes; all transitions use widening/deepening

## Material Inventory

### Material Inventory - Primary Motif / Gesture
- Identity: Three-note falling-settling cell (C3-Ab2-G2) functioning as carrier memory
- First form: Soft carrier phrase during orientation after ground established (3:00 mark)
- Later forms: Transposed to Eb2-C2-Bb1 in deepening; fragmented into Ab2-G2 in core work

### Material Inventory - Harmonic Signature
- Home color: F root with open C, Eb warmth (F3-C4-Eb4), G add9 (G4)
- Contrast color: Db luminous shadow with common-tone F (Db3-F3-Ab4), minor 7th added
- Return color: F root with fewer tones (F3-C4), softened upper partials, narrower spatial field

### Material Inventory - Texture Family
- Continuous layer behavior: Ground drone with 8-45s attack, 20-60s release; harmonic pad arpeggio (delayed processed)
- Event layer behavior: Rare submerged motif fragments at 15-45s intervals; soft partial blooms (0.25-3s duration)
- Noise / air behavior: Filtered high air at edges with 10-60s attack, 20-90s release; opens only after carrier phrase

### Material Inventory - Spatial Material
- Width behavior: Narrow (0:00) → medium (3:00) → wide (10:00) → medium-wide (16:00) → narrow (23:00)
- Motion behavior: Slow drift across stereo field; air layer moves from edges to rear
- Depth behavior: Near (orientation) → deepening (7:00) → stable depth (13:00) → re-deepening (21:00)

### Material Inventory - Modulation Identity
- Rate family: Ground drone (0.07-0.13 Hz), harmonic pad (0.15-0.35 Hz), air bloom (asymmetric shimmer)
- Change rule: Modulation rates slow as depth increases; ground drone rate decreases 0.01 Hz per minute

### Material Inventory - Hypnotist-Voice Analog
- Reference cadence profile: reference_voice_cadence_profile_v1 (6.0-14.0s phrases, 1.0-3.0s rests)
- Reference pitch-contour profile: reference_voice_pitch_contours_v1 (84.5% falling-settling)
- Carrier instrument / layer: Sarangi-like bowed string (warm low-mid reed patch)
- Cadence behavior: Breath-length phrases with permissive pauses; downward settling at deepening
- Contour behavior: 84.5% falling-settling, 8.2% rising-opening (fractionation), 3.6% scoop-then-settle
- Weighting behavior: Slight register warmth at phrase ends; harmonic reinforcement on settling notes
- Return behavior: Contour returns transformed (transposed, wider) at depth thresholds
- Salience limit: 6dB above harmonic bed, 10dB above substrate; never becomes foreground melody

### Material Inventory - Nonverbal Anchors And Subtle Triggers
- Anchor identity: Tiny low-mid warmth bloom (100-250Hz) paired with carrier release
- First pairing: Orientation at 3:15 (after first carrier phrase resolves)
- Withholding plan: Absent for 90s after first pairing (until induction threshold at 7:00)
- Return / trigger plan: Induction threshold (7:00), deepening stability point (13:00), core reassurance (18:00), fractionation re-deepening (21:30), integration (22:45)
- Salience policy: Audible enough to learn (10dB above substrate), not salient enough to monitor

## Development Grammar

- Establishment rule: Introduce carrier with first motif cell over ground drone (orientation)
- Variation rule: Transform motif by register, density, or spatial placement per stage
- Contrast rule: Shift harmonic color (F→Db) during deepening; return to F with fewer tones
- Recurrence rule: Carrier contour returns transformed at depth thresholds (not identical)
- Foreground rule: Carrier maintains 6dB above bed in all sections; no section without carrier
- Withholding rule: Anchor absent for 90s after first pairing; event layer withheld in orientation
- Fractionation rule: Lightening via brief carrier brightness (20:00-21:00), re-deepening via wider spatial field (21:00-22:00)
- Trigger conditioning rule: Anchor paired with carrier release during comfort moments
- Dissolution / cadence rule: Final fade uses harmonic simplification (F→F3) and spatial contraction
- Anti-padding rule: No looped events; all micro-events serve development (15-45s intervals)

## Orchestration Map

- Root / ground function: Carbon-based lifeforms solar fields drone (centered)
- Harmonic color function: F major with Eb warmth, Db contrast
- Motion function: Slow modulation rates (0.07-0.35 Hz)
- Foreground / event function: Carrier phrases (6-14s), motif fragments
- Voice-adjacent induction function: Sarangi-like carrier with falling-settling contour
- Anchor / trigger function: Low-mid warmth bloom (100-250Hz) at carrier release
- Air / bloom function: Filtered high air (12kHz+) at edges and rear
- Spatial / depth function: Width arc narrow→wide→narrow; air layer creates depth
- Silence / restraint function: Withheld anchor for 90s after first pairing

## Temporal Behavior

- Micro-event rate: Every 15-45 seconds (motif fragments, partial blooms)
- Scene-change rate: Every 75-150 seconds (harmonic shifts, density changes)
- Long-wave change: Harmonic color shift from F→Db during deepening
- Maximum stasis tolerance: 45 seconds without deliberate change or withholding
- Repetition policy: Motif returns transformed; no identical loops
- Fractionation timing: Lightening 20:00-21:00 (carrier brightness), re-deepening 21:00-22:00 (wider field)
- Anchor recurrence spacing: 3:15, 7:00, 13:00, 18:00, 21:30, 22:45 (all within stage duration)

## Spatial Composition

- Stereo requirement: Stereo
- Spatial arc: Narrow (0:00) → medium (3:00) → wide (10:00) → medium-wide (16:00) → narrow (23:00)
- Layer placement principles: Ground centered, harmonic body wide-stable, carrier near-center-low-motion, air at edges/rear, anchor local-but-soft
- Motion limits: No fast autopan; spatial motion over 20-120s only for tiny anchor gestures
- Verification obligation: Verify not mono, dual-mono; width arc audible and motion not alerting

## Revision Criteria

- Failure mode: too static
  - Evidence: No micro-events for >45s; harmonic color unchanged
  - Revision target: Add motif fragment or partial bloom at 45s intervals

- Failure mode: weak fractionation
  - Evidence: Lightening feels like reset; re-deepening not deeper
  - Revision target: Reduce fractionation brightness to 10dB above substrate; strengthen re-deepening via wider field

- Failure mode: weak anchors / triggers
  - Evidence: Anchor absent at depth thresholds; pairing not meaningful
  - Revision target: Move anchor returns to exact threshold moments (7:00, 13:00 etc.)

- Failure mode: weak voice-adjacent induction
  - Evidence: Carrier not continuous; contour not falling-settling (84.5%)
  - Revision target: Ensure carrier present in all sections; adjust contour to match empirical profile

- Failure mode: weak hypnotic architecture
  - Evidence: No depth trajectory; stages feel like new songs
  - Revision target: Map harmonic density, register descent, and spatial width to depth progression
