## Artistic Reading

- User image / premise: Slow dreamlike journey through crystalline forest at twilight
- Musical problem: Translate organic luminosity and subtle movement into continuous field without alerting cues
- Listener stance: Following the carrier's breath-length phrasing as a non-intrusive guide
- What this is not: Pop melody, bright percussion, dramatic tension, or visual metaphor in sound
- Style-family fit: Adapted from drone_sustained_tone and micropolyphony_texture with spectral color focus

## Chosen Musical Premise

- Premise sentence: A continuous field of low-mid resonance evolves through organic micro-shifts, guiding attention from external orientation to deep absorption via luminous harmonic color and spatial breath.
- Primary dramatic motion: Establish → deepen → dissolve
- Sound-world metaphor: Crystalline forest at twilight where light refracts through ice-like structures
- Musical consequence: Harmonic color shifts (F→Db) create luminous refraction effects; spatial width arc mirrors forest canopy openness
- Duration rationale: 30 minutes earned through three major harmonic regions (orientation, deepening, core) with fractionation as a natural refraction event

## Hypnotic Function Architecture

- Target use: music-only self-hypnosis
- Stage map:
  - Orientation / Settling (4:00): baseline → light; establish field and first carrier pairing
  - Induction / Narrowing (5:00): light → medium; pace attention inward via carrier phrasing
  - Deepening (7:00): medium → deep; reduce orienting load through harmonic narrowing
  - Core Absorptive Work (10:00): deep; sustain absorption via harmonic resonance
  - Fractionation Pocket (2:00): deep → light-medium → deep; brief refraction event
  - Integration / Stabilization (1:30): medium → light; return to calm via harmonic simplification
  - Return / Reorientation (0:30): light → baseline; dissolve field with spatial contraction
- Depth trajectory: Baseline (87.31 Hz) → light (92.5 Hz) → medium (89.7 Hz) → deep (86.1 Hz) → light-medium (88.2 Hz) → calm (90.4 Hz)
- Pacing-and-leading plan: First establish slow ground with sparse carrier, then lengthen rests and lower register to narrow attention
- Ratification plan: Carrier returns with transformed contour at each depth threshold (induction, deepening stability)
- Suggestion-compatible windows: 7:30-9:00, 14:00-18:00, 23:00-24:00
- Reset avoidance rule: No abrupt cuts, hard transients, or brightness spikes; all transitions follow spectral arc

## Material Inventory

### Material Inventory - Primary Motif / Gesture
- Identity: Three-note falling cell (C3-Ab2-G2) with 0.8s decay
- First form: Soft carrier phrase during orientation after ground established (3:00 mark)
- Later forms: Lowered register in deepening, thinned to two notes in core work

### Material Inventory - Harmonic Signature
- Home color: F2 root with open C3, Eb4 warmth (interval stack [0, 3, 10])
- Contrast color: Db2 root with F4 common tone (interval stack [0, 5, 10])
- Return color: F2 root with reduced partials (interval stack [0, 3])

### Material Inventory - Texture Family
- Continuous layer behavior: Substrate with slow beating (87.31 Hz ±0.2 Hz)
- Event layer behavior: Rare motif fragments (one per 45s) with spectral bloom
- Noise / air behavior: Filtered high air (200-1800 Hz) opening/closing at 30s intervals

### Material Inventory - Spatial Material
- Width behavior: Narrow (15°) → medium (45°) → wide (90°) → medium-wide (60°) → narrow (15°)
- Motion behavior: Slow drift across stereo field during deepening, static in core
- Depth behavior: Reverb tail shortens from 3s to 0.5s across piece

### Material Inventory - Modulation Identity
- Rate family: Slow breath (0.07-0.13 Hz) with asymmetric shimmer
- Change rule: Rates evolve from 0.07 to 0.13 Hz over piece, peaking at fractionation

### Material Inventory - Hypnotist-Voice Analog
- Reference cadence profile: v1 empirical profile (6-14s phrases, 0.5-3s pauses)
- Reference pitch-contour profile: Falling_settling (84.5%) dominant
- Carrier instrument / layer: Sarangi-like bowed string with soft attack (0.25s)
- Cadence behavior: Breath-length phrase arcs, downward settling at deepening
- Contour behavior: Falling_settling with 0.8s weighted stress at phrase end
- Weighting behavior: Slight register warmth on stressed notes (C3→B2)
- Return behavior: Transformed contour at depth thresholds (e.g., deeper register in return)
- Salience limit: 6dB above harmonic bed, 10dB above substrate

### Material Inventory - Nonverbal Anchors And Subtle Triggers
- Anchor identity: Tiny low-mid warmth bloom (87.31 Hz + 0.5Hz beat)
- First pairing: Orientation at 3:20 (carrier phrase resolves into bloom)
- Withholding plan: Absent for 150s after first pairing
- Return / trigger plan: Induction threshold (4:30), deepening stability (12:00), core reassurance (20:00), fractionation re-deepening (21:30)
- Salience policy: Audible enough to learn, not salient enough to monitor

## Development Grammar

- Establishment rule: Introduce substrate and harmonic bed before carrier
- Variation rule: Harmonic regions shift via crossfaded interval stacks (F→Db)
- Contrast rule: Brightness opens only during fractionation, never to alerting levels
- Recurrence rule: Motif returns transformed (register shift + density thinning)
- Foreground rule: Carrier remains foreground throughout; events submerge after 1s
- Withholding rule: Anchor absent for 150s post-first pairing; motif fragments limited to one per 45s
- Fractionation rule: Lightening via spectral bloom (2000→3800 Hz) for 60s, then re-deepening via harmonic narrowing
- Trigger conditioning rule: Anchor pairs with carrier release; return at depth thresholds
- Dissolution / cadence rule: Final fade combines spatial contraction and harmonic simplification
- Anti-padding rule: No looped events; all material must transform or dissolve

## Orchestration Map

- Root / ground function: Substrate at 87.31 Hz
- Harmonic color function: Harmonic bed with interval stacks
- Motion function: Carrier's breath-length phrasing
- Foreground / event function: Motif fragments and air blooms
- Voice-adjacent induction function: Sarangi carrier with weighted cadence
- Anchor / trigger function: Low-mid warmth bloom at depth thresholds
- Air / bloom function: Filtered high air with slow opening/closing
- Spatial / depth function: Stereo width and reverb tail evolution
- Silence / restraint function: Anchor withholding for 150s post-first pairing

## Temporal Behavior

- Micro-event rate: One meaningful emergence per 45 seconds
- Scene-change rate: Every 7 minutes (harmonic region shifts)
- Long-wave change: Spectral arc from 200→3800 Hz → 2600 Hz
- Maximum stasis tolerance: 45 seconds without meaningful change
- Repetition policy: Motif returns transformed, not identical
- Fractionation timing: Lightening 26:00-27:00, re-deepening 27:00-28:00
- Anchor recurrence spacing: First pairing (3:20), induction threshold (4:30), deepening stability (12:00), core reassurance (20:00), fractionation re-deepening (21:30)

## Spatial Composition

- Stereo requirement: stereo
- Spatial arc: Narrow → medium → wide → medium-wide → narrow
- Layer placement principles: Ground centered, harmonic bed wide-stable, carrier near-center low-motion, air at edges
- Motion limits: No fast autopan; spatial motion limited to 20°/second max
- Verification obligation: Verify not mono, width arc audible, motion non-alerting

## Revision Criteria

- Failure mode: too static
  - Evidence: No harmonic shift or event for >45s in core work
  - Revision target: Add motif fragment at 20:00 with transformed contour

- Failure mode: weak fractionation
  - Evidence: Lightening feels like new section, not refraction
  - Revision target: Bind lightening to carrier contour shift (not separate event)

- Failure mode: weak anchors
  - Evidence: Anchor at 12:00 too obvious, not paired with carrier release
  - Revision target: Soften onset to 0.1s, pair precisely with carrier phrase end

- Failure mode: weak ending
  - Evidence: Final fade without spatial contraction or harmonic simplification
  - Revision target: Add spatial narrowing to 15° over final 30s

- Failure mode: weak hypnotic architecture
  - Evidence: No depth trajectory; stages feel arbitrary
  - Revision target: Map harmonic color to depth (F2=baseline, Db=deep)
