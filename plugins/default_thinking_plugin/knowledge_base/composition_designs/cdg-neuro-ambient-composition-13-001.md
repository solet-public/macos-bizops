## Artistic Reading

- User image / premise: A deep, breath-like descent into resonant inner space with voice-adjacent carrier as hypnotic guide
- Musical problem: Creating continuous trance depth without alerting the listener through abrupt changes or foreground events
- Listener stance: Passive absorption with minimal orienting load, allowing internal focus without external monitoring
- What this is not: A rhythmic track with beats or a melodic composition; no vocal samples, percussion, or attention-demanding elements
- Style-family fit: Sequenced Ambient (Carbon Based Lifeforms/Solar Fields tradition) with hypnotic stage architecture

## Chosen Musical Premise

- Premise sentence: A breath-length descent through harmonic regions using a voice-adjacent carrier to guide depth transitions without alerting the listener
- Primary dramatic motion: Deepening → fractionation lightening → deeper return (with no reset)
- Sound-world metaphor: A resonant cave where sound echoes through layers of stone, with each layer revealing more depth
- Musical consequence: Harmonic regions shift via common-tone transitions; carrier phrases settle downward to trigger anchor blooms
- Duration rationale: 24 minutes allows for three distinct depth plateaus (light, medium, deep) with fractionation cycles to prevent habituation

## Hypnotic Function Architecture

- Target use: Music-only self-hypnosis with structured hypnotic stages
- Stage map:
  - Orientation / Settling: 3:00, baseline-to-light depth, establishes anchor and carrier
  - Induction / Narrowing: 4:00, light-to-medium depth, introduces carrier pacing
  - Deepening: 6:00, medium-to-deep depth, widens space and softens anchor
  - Core Absorptive Work: 7:00, deep depth, sustains with rare motif fragments
  - Fractionation Pocket: 2:00, deep-to-light-medium-to-deep depth, brief brightness lightening
  - Integration / Stabilization: 1:30, medium-to-light depth, prepares for return
  - Return / Reorientation: 0:30, light-to-baseline depth, gentle field contraction
- Depth trajectory: Spectral centroid moves from 1800 Hz (baseline) → 950 Hz (light) → 620 Hz (medium) → 410 Hz (deep), with fractionation lightening to 850 Hz then re-deepening
- Pacing-and-leading plan: First establish anchor (3:00), then lengthen carrier phrase gaps to narrow attention, finally widen space during deepening
- Ratification plan: Anchor blooms return at depth thresholds (induction, stability point, core reassurance) to confirm state
- Suggestion-compatible windows: 7:30-9:00 (deepening), 13:00-18:30 (core work), 22:00-23:00 (integration)
- Reset avoidance rule: No abrupt brightness spikes, no section boundaries without 12-second crossfades

## Material Inventory

### Material Inventory - Primary Motif / Gesture
- Identity: Three-note falling-settling cell (C3-Ab2-G2) with 0.9s phrase duration
- First form: Soft carrier phrase during orientation after ground established (3:15)
- Later forms: Lower-slower-deepening form (deepening stage), thinned-core-fragment (core work), clearer-integration-return (integration)

### Material Inventory - Harmonic Signature
- Home color: F minor 7th (F-Ab-C-Eb) with open fifth voicing (F and C as outer voices)
- Contrast color: Eb major 7th with added Ab (Eb-G-Bb-D-Ab) creating suspended warmth
- Return color: F minor triad (F-Ab-C) with softened upper partials and omitted 7th

### Material Inventory - Texture Family
- Continuous layer behavior: Warm low-mid drone with slow beating (0.5 Hz) and long attack
- Event layer behavior: Rare submerged motif fragments (one per stage, 5-10s duration)
- Noise / air behavior: Filtered high air (2000-12000 Hz) with slow opening/closing (60s cycles)

### Material Inventory - Spatial Material
- Width behavior: Narrow (0-3:00) → medium (3:00-7:00) → wide (7:00-13:00) → medium-wide (13:00-20:00) → narrow (20:00-24:00)
- Motion behavior: Slow drift in air layer (0.05 Hz) with gentle eddies
- Depth behavior: Near-field anchor → deepening field (13:00) → retracted to near at return

### Material Inventory - Modulation Identity
- Rate family: Incommensurable rates (0.08 Hz, 0.13 Hz, 0.21 Hz) for field voices; theta entrainment (5.5 Hz) on carrier
- Change rule: Modulation depth decreases from 0.08 → 0.04 across piece; rates slow during deepening

### Material Inventory - Hypnotist-Voice Analog
- Reference cadence profile: reference_voice_cadence_profile_v1
- Reference pitch-contour profile: falling_settling (Orientation), downward-settling (Induction/Deepening)
- Carrier instrument / layer: Warm low-mid reed-like MIDI layer (GM program 89)
- Cadence behavior: Breath-length phrase arcs (4-16s) with 0.75s permissive pauses
- Contour behavior: Downward settling (phrases end with pitch descent)
- Weighting behavior: Slight emphasis on last note via warmer timbre and 0.2s longer sustain
- Return behavior: Returns transformed (lower register, slower rate) at depth thresholds
- Salience limit: Carrier remains below lead melody attention (max -12 dBFS)

### Material Inventory - Nonverbal Anchors And Subtle Triggers
- Anchor identity: Tiny low-mid warmth bloom (0.5s, 120-300 Hz) at carrier release
- First pairing: Orientation stage (3:15), paired with first carrier phrase resolution
- Withholding plan: Absent 90s after pairing (until induction threshold)
- Return / trigger plan: Returns at induction threshold (7:00), deepening stability point (13:00), core reassurance (18:00), fractionation re-deepening (21:30), integration (22:45)
- Salience policy: Audible enough to learn (0.3s at -18 dBFS), not salient enough for monitoring

## Development Grammar

- Establishment rule: Anchor drone enters first (0:00), harmonic bed fades in at 2:30
- Variation rule: Shift between home/contrast colors via common-tone transitions (F→Ab)
- Contrast rule: Contrast color appears only during deepening for 30s, never as primary
- Recurrence rule: Primary motif returns transformed at each depth threshold (register shift, density thinning)
- Foreground rule: One meaningful emergence per stage (motif fragment in Core/Fractionation)
- Withholding rule: Anchor withheld 90s after first pairing; new harmonic regions introduced only after previous settles
- Fractionation rule: Lightening (20:00-21:00): spectral centroid rises to 850 Hz, density thins; re-deepening (21:00-22:00): centroid returns to 410 Hz
- Trigger conditioning rule: Anchor paired with downward carrier phrases, creating comfort association at depth thresholds
- Dissolution / cadence rule: Final 30s contract field to narrow width, return home color in simplified form
- Anti-padding rule: No identical loops; every event must serve depth progression (e.g., motif fragments only in Core/Fractionation)

## Orchestration Map

- Root / ground function: Anchor drone (F2, 87.31 Hz) with slow beating
- Harmonic color function: Harmonic bed (F minor 7th → Eb major 7th)
- Motion function: Air layer with slow spectral drift (0.05 Hz)
- Foreground / event function: Primary motif fragment in Core/Fractionation
- Voice-adjacent induction function: Reed-like carrier layer (breath-length phrases)
- Anchor / trigger function: Tiny warmth bloom at carrier release
- Air / bloom function: High air layer (2000-12000 Hz) with slow opening
- Spatial / depth function: Stereo width arc (narrow → wide → narrow)
- Silence / restraint function: Anchor withheld 90s after first pairing

## Temporal Behavior

- Micro-event rate: One meaningful event every 15-45 seconds (motif fragment, anchor return)
- Scene-change rate: Harmonic region shifts every 75-120 seconds
- Long-wave change: Spectral centroid moves from 1800 Hz → 410 Hz → 950 Hz
- Maximum stasis tolerance: 45 seconds without deliberate change (prevents habituation)
- Repetition policy: Events transform on recurrence (e.g., motif returns lower/slower)
- Fractionation timing: Lightening 20:00-21:00, re-deepening 21:00-22:00
- Anchor recurrence spacing: First at 3:15, then withheld until induction (7:00), then at depth thresholds

## Spatial Composition

- Stereo requirement: Stereo
- Spatial arc: Narrow (0-3:00) → medium (3:00-7:00) → wide (7:00-13:00) → medium-wide (13:00-20:00) → narrow (20:00-24:00)
- Layer placement principles: Anchor centered, harmonic bed wide stable, carrier near-center low motion, air at edges/rear
- Motion limits: No autopan >0.1 Hz; slow drift only (0.05-0.1 Hz)
- Verification obligation: Verify not mono, width arc audible, motion not alerting

## Revision Criteria

- Failure mode: too static
  - Evidence: No harmonic shifts or density changes beyond 90s in Core stage
  - Revision target: Add spectral shift (centroid to 410 Hz) and introduce motif fragment

- Failure mode: weak recurrence
  - Evidence: Primary motif appears once without transformation in Core stage
  - Revision target: Transform motif (lower register, slower rate) at each depth threshold

- Failure mode: weak fractionation
  - Evidence: Lightening creates abrupt brightness spike (20:00) and re-deepening feels like reset
  - Revision target: Lighten via spectral centroid rise (850 Hz) without brightness spike; re-deepen over 60s

- Failure mode: weak anchors / triggers
  - Evidence: Anchor bloom too frequent (every 30s) and audible as notification sound
  - Revision target: Reduce anchor to one per depth threshold; soften onset (0.1s attack, -24 dBFS)

- Failure mode: weak voice-adjacent induction
  - Evidence: Carrier phrases too rhythmic (0.5s intervals) and bright at peak
  - Revision target: Lengthen phrases to 4-16s; soften brightness (max 2000 Hz) and add permissive pauses
