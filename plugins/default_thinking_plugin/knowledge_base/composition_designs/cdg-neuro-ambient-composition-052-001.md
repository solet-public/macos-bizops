## Artistic Reading

- User image / premise: continuous voice-led induction with layered depth and spatial awareness
- Musical problem: how to create a non-intrusive lead that guides through seven hypnotic stages without foreground dominance or abrupt changes
- Listener stance: following the continuous lead, moving from broad environmental to internal absorption and gentle reorientation
- What this is not: dramatic, sad narrative, triumphant, pop-hook-based, cinematic tension
- Style-family fit: neuro-ambient with voice-adjacent induction (subfamily using instrumental carrier for hypnotic pacing)

## Chosen Musical Premise

- Premise sentence: A continuous breath-length carrier guides the listener through seven hypnotic stages using a falling-settling motif and harmonic evolution to deepen absorption without alerting the listener
- Primary dramatic motion: establish, vary, deepen, fractionate, stabilize, return
- Sound-world metaphor: a slow-moving river that deepens and widens as it flows, with gentle eddies (fractionation) before returning to a calm pool
- Musical consequence: river metaphor changes harmony via harmonic signature shifts, texture through density and event behavior, register by lowering as depth increases, space through widening then narrowing
- Duration rationale: 24 minutes allows seven-stage progression with sufficient time for depth trajectory and micro-developments without feeling rushed

## Hypnotic Function Architecture

- Target use: music-only self-hypnosis
- Stage map:
  - Orientation / Settling: 0:00-3:00, target depth: baseline to light, musical function: settle and establish safety
  - Induction / Narrowing: 3:00-7:00, target depth: light to medium, musical function: pace and lead attention inward
  - Deepening: 7:00-13:00, target depth: medium to deep, musical function: reduce orienting load and stabilize root memory
  - Core Absorptive Work: 13:00-20:00, target depth: deep, musical function: sustain absorption with non-inert microdevelopment
  - Fractionation Pocket: 20:00-22:00, target depth: deep to light-medium to deep, musical function: briefly lighten then return deeper
  - Integration: 22:00-23:30, target depth: medium to light, musical function: stabilize and prepare for return
  - Return / Reorientation: 23:30-24:00, target depth: light to baseline, musical function: dissolve and reorient
- Depth trajectory: baseline → light → medium → deep → light-medium → medium → baseline (via spectral narrowing and harmonic simplification)
- Pacing-and-leading plan: first pace broad listening with slow ground and sparse carrier, then lengthen rests (induction), lower register (deepening), darken brightness (core work), widen space (deepening)
- Ratification plan: carrier's downward settling contour and anchor cues at thresholds confirm accepted state without words
- Suggestion-compatible windows: none (music-only self-hypnosis)
- Reset avoidance rule: no abrupt cuts, hard transients, alerting cues, or sudden brightness spikes

## Material Inventory

### Material Inventory - Primary Motif / Gesture

- Identity: three-note falling-settling cell (C3-Ab2-G2) in carrier
- First form: soft, sparse phrase during orientation after ground established (0:45-1:30)
- Later forms: 
  - Deepening: lower register (B2-G2-Eb2), slower, wider spatial placement
  - Core Work: thinned fragment (Ab2-G2) with longer decay, embedded in harmonic bed
  - Integration: clearer return at C3-Ab2-G2 with softer attack and wider placement

### Material Inventory - Harmonic Signature

- Home color: F2 root with open C (F-C), Eb warmth (F-Eb), G add9 (F-G-Bb-D) — interval stack [0,7,10] in low register
- Contrast color: Db2 root with common-tone F (Db-F-Ab) and G add9 (Db-G-Bb-D), interval stack [0,4,7] — luminous shadow with F retained
- Return color: F2 root with only open C (F-C) and Eb warmth (F-Eb), interval stack [0,7] — fewer tones, softened upper partials, narrower field

### Material Inventory - Texture Family

- Continuous layer behavior: warm centered F2 drone (ground) with slow beating; harmonic body pad using open voicings, evolving via filter motion
- Event layer behavior: rare submerged motif fragments (core work/fractionation) and soft partial blooms (at anchor returns)
- Noise / air behavior: filtered high air at edges with slow opening/closing (air bloom), increasing width during deepening

### Material Inventory - Spatial Material

- Width behavior: narrow (orientation) → medium (induction) → wide (deepening) → medium-wide (core work) → narrower (fractionation) → wider (integration) → contracting (return)
- Motion behavior: slow wide drift in deepening; minimal motion elsewhere except anchor cues (tiny spatial softening)
- Depth behavior: near-field in orientation, deepening to resonant field during core work, narrowing for return

### Material Inventory - Modulation Identity

- Rate family: slow breath (0.07-0.13 Hz) for ground/harmonic body; asymmetric shimmer (multiple incommensurable slow rates) for air bloom
- Change rule: modulation rate increases slightly during deepening (0.15-0.25 Hz) then recedes during integration

### Material Inventory - Hypnotist-Voice Analog

- Reference cadence profile: v1 empirical profile (84.5% falling_settling)
- Reference pitch-contour profile: falling_settling dominant (orientation/induction/deepening), rising_opening for fractionation
- Carrier instrument: sarangi-like bowed string (warm low-mid resonance)
- Cadence behavior: breath-length phrase arcs (0.9-3.3s) with 0.5-1.8s rests, weighted emphasis on downward settling
- Contour behavior: primarily falling_settling; brief rising_opening during fractionation lightening
- Weighting behavior: slight register warmth and harmonic reinforcement at phrase end (not loudness)
- Return behavior: transformed motif returns at thresholds with contour shifts
- Salience limit: foreground lead ≥6 dB above harmonic bed, ≥10 dB above substrate

### Material Inventory - Nonverbal Anchors And Subtle Triggers

- Anchor identity: tiny low-mid warmth bloom (0.5s, 120-180 Hz) paired with carrier release
- First pairing: orientation at 2:30 (after first carrier phrase resolves)
- Withholding plan: absent for ≥90s after first pairing (until induction threshold)
- Return / trigger plan: 
  - Induction threshold: 3:45
  - Deepening stability: 10:00
  - Core reassurance: 16:30
  - Fractionation re-deepening: 21:45
  - Integration: 23:00
- Salience policy: audible enough to learn (120-180 Hz, 3 dB above bed) but not salient enough to monitor

## Development Grammar

- Establishment rule: introduce ground, harmonic bed, and carrier with sparse motif in orientation
- Variation rule: transform primary motif by register (lowering) and density (thinning) in deepening
- Contrast rule: shift to Db contrast color during core work with F retained for harmonic surprise without disorientation
- Recurrence rule: motif returns transformed at each major threshold (induction, deepening stability, etc.)
- Foreground rule: carrier always foreground (≥6 dB above bed) in all sections
- Withholding rule: withhold anchor for 90s after first pairing to preserve meaning
- Fractionation rule: lightening (20:00-21:00) via brighter carrier contour and wider field; re-deepening (21:00-22:00) via darker contour and narrower field
- Trigger conditioning rule: anchor paired with carrier release at comfort points (first pairing, then returns at thresholds)
- Dissolution / cadence rule: return to home color with fewer tones and narrower field; fade out air bloom
- Anti-padding rule: no looped events or stretched textures without development

## Orchestration Map

- Root / ground function: warm centered F2 drone (ground layer)
- Harmonic color function: dark low-mid pad using F-centered open voicings (harmonic body layer)
- Motion function: carrier's breath-length phrase arcs and harmonic bed evolution
- Foreground / event function: carrier's motif fragments and anchor cues (rare events)
- Voice-adjacent induction function: sarangi-like carrier with breath-length phrases
- Anchor / trigger function: low-mid warmth bloom (anchor layer)
- Air / bloom function: filtered high air at edges with slow opening/closing (air bloom layer)
- Spatial / depth function: stereo width arc from narrow to wide to narrow
- Silence / restraint function: withholding anchor for 90s after first pairing

## Temporal Behavior

- Micro-event rate: one event every 20-35 seconds (motif fragments, anchor returns)
- Scene-change rate: every 7-10 minutes (at stage boundaries with soft crossfades)
- Long-wave change: harmonic signature shifts at each stage boundary
- Maximum stasis tolerance: 45 seconds without meaningful change (e.g., no anchor return)
- Repetition policy: motif returns transformed; harmonic bed changes at stage boundaries
- Fractionation timing: lightening 20:00-21:00, re-deepening 21:00-22:00
- Anchor recurrence spacing: first pairing (2:30), induction threshold (3:45), deepening stability (10:00), core reassurance (16:30), fractionation re-deepening (21:45), integration (23:00)

## Spatial Composition

- Stereo requirement: stereo
- Spatial arc: narrow → medium → wide → medium-wide → narrower → wider → contracting (to narrow)
- Layer placement principles: ground centered, harmonic body wide stable, carrier near center low motion, air at edges and rear, anchor local but soft
- Motion limits: no fast autopan; spatial motion over 20-120 seconds is tiny (e.g., anchor softening)
- Verification obligation: verify not mono, width arc audible and motion not alerting

## Revision Criteria

- Failure mode: too static
  - Evidence: no perceptible change for >45 seconds in any unit
  - Revision target: add micro-event (motif fragment or anchor return) at 30-45 second intervals

- Failure mode: too generic
  - Evidence: harmonic bed and carrier sound like any ambient piece
  - Revision target: use specific interval stacks per stage (as defined) and primary motif

- Failure mode: too busy
  - Evidence: more than one event per 15 seconds
  - Revision target: reduce event density to one every 20-35 seconds

- Failure mode: weak recurrence
  - Evidence: motif does not return transformed at thresholds
  - Revision target: ensure motif returns in deepening (lower register), core work (thinned fragment), integration (clearer)

- Failure mode: weak ending
  - Evidence: fades out without harmonic simplification or spatial contraction
  - Revision target: simplify to F-C open fifth and contract width to narrow

- Failure mode: weak spatial composition
  - Evidence: stereo field static or mono
  - Revision target: implement full width arc with layer placement

- Failure mode: weak hypnotic architecture
  - Evidence: no clear stage progression (depth doesn't change as described)
  - Revision target: adjust harmonic bed and carrier contour to match stage depth targets

- Failure mode: weak fractionation
  - Evidence: lightening feels like reset or new section
  - Revision target: ensure carrier contour during lightening is brief and clear, then re-deepens without harmonic change

- Failure mode: weak anchors / triggers
  - Evidence: anchor cues too frequent or not paired with carrier release
  - Revision target: follow recurrence spacing and pairing rule (first at 2:30, returns at thresholds)

- Failure mode: weak voice-adjacent induction
  - Evidence: carrier too bright or mechanical
  - Revision target: use sarangi-like timbre, breath-length phrases (0.9-3.3s), downward settling contour
